# 우리 반 노래공방 🎶

초등학생이 우리 반 이야기와 노래 분위기를 선택하면, AI에게 노래 가사를 요청할 최종 프롬프트를 만들어 주는 웹사이트입니다.

## 사용 방법

1. 학년·반, 우리 반 단어 3개, 재미있었던 일, 자랑거리를 입력합니다. 보기 버튼을 눌러 쉽게 채울 수 있습니다.
2. 노래 분위기 6종과 여자·남자·아이들 목소리 중 하나를 고릅니다.
3. 제목과 전하고 싶은 말은 선택해서 입력합니다.
4. **우리 반 프롬프트 만들기**를 누르고 완성된 프롬프트를 복사합니다.
5. 선생님과 함께 사용하는 AI 채팅창에서 가사를 생성하고 검토한 뒤, Suno의 가사 입력란에 붙여 넣습니다.

## 포함된 필수 규칙

- 친구들을 놀리거나 상처 주는 표현은 사용하지 마.
- 노래 길이는 약 1분 정도로 해 줘.
- 가사는 [Verse], [Chorus] 형식으로 구분해 줘.
- Suno AI에 바로 복사해서 사용할 수 있도록 가사만 출력해 줘.

## 구성

별도 설치나 빌드 없이 동작하는 HTML, CSS, JavaScript 사이트입니다. `index.html`을 열거나 정적 웹 서버에서 실행하세요. GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시하도록 설정하면 됩니다.

- `index.html`: 입력 화면과 결과 영역
- `style.css`: PC·태블릿·모바일 레이아웃
- `app.js`: 보기 선택, 입력 확인, 프롬프트 생성·복사
- `favicon.svg`: 사이트 아이콘

## 데이터와 서비스

회원가입, API 키, 서버, 외부 라이브러리 없이 동작합니다. 학생 입력을 서버나 브라우저 저장소에 기록하지 않으며, 새로고침하면 지워집니다. 복사 버튼을 누르면 프롬프트가 기기의 클립보드에 들어갑니다. 이후 사용자가 AI 서비스에 붙여 넣는 내용은 해당 서비스로 전달됩니다.

이 사이트는 프롬프트 생성 도구입니다. AI 가사나 음악을 직접 생성하거나 Suno에 자동으로 전송하지 않습니다. 실제 곡 길이는 음악 생성 결과에 따라 달라질 수 있습니다.
